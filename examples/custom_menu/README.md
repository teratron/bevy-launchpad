# Описание примера `custom_menu`

Этот пример демонстрирует создание расширенного главного меню с дополнительными кнопками:

- "Level Select" — ведет в состояние `LevelSelect`
- "Credits" — ведет в состояние `Credits`

**Ассеты**: Для данного примера не требуются специфические дополнительные файлы, он использует встроенные стили библиотеки.
