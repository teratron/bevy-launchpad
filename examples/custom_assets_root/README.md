# Ассеты для запуска примера `custom_assets_root`

Для корректной работы этого примера необходимо вручную создать папку `game_data/` и добавить в неё следующий файл:

- `game_data/branding/logo.png` — Логотип

Пример настроен на использование `game_data/` в качестве корневой папки ресурсов вместо стандартной `assets/`.
