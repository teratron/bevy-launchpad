# Ассеты для запуска примера `custom_theme_dark`

Для корректной работы этого примера необходимо вручную добавить следующие файлы:

- `examples/custom_theme_dark/assets/fonts/NotoSans-Regular.ttf` — Шрифт Noto Sans (Regular)
- `examples/custom_theme_dark/assets/fonts/NotoSans-Bold.ttf` — Шрифт Noto Sans (Bold)

Шрифты необходимы для корректного отображения текста в пользовательской теме.
