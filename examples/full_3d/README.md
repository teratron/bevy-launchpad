# Ассеты для запуска примера `full_3d`

Для корректной работы этого примера необходимо вручную добавить следующие файлы (обозначены ✋ в спецификации):

- `examples/full_3d/assets/branding/legal.png` — Экран правовой информации
- `examples/full_3d/assets/branding/publisher.png` — Логотип издателя
- `examples/full_3d/assets/branding/developer.png` — Логотип разработчика
- `examples/full_3d/assets/branding/engine.png` — Логотип движка
- `examples/full_3d/assets/fonts/Orbitron-Regular.ttf` — Шрифт Orbitron (Regular)
- `examples/full_3d/assets/fonts/Orbitron-Bold.ttf` — Шрифт Orbitron (Bold)

Эти файлы необходимы для отображения полной последовательности сплеш-экранов и стилизации текста.
