# Ассеты для запуска примера `full_2d`

Для корректной работы этого примера необходимо вручную добавить следующие файлы (обозначены ✋ в спецификации):

- `examples/full_2d/assets/branding/studio_logo.png` — Логотип студии
- `examples/full_2d/assets/branding/game_logo.png` — Логотип игры
- `examples/full_2d/assets/fonts/NotoSans-Regular.ttf` — Шрифт Noto Sans (Regular)
- `examples/full_2d/assets/fonts/NotoSans-Bold.ttf` — Шрифт Noto Sans (Bold)

Эти файлы необходимы для отображения сплеш-экранов и корректного рендеринга русского текста.
