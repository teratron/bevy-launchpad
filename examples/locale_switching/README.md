# Ассеты для запуска примера `locale_switching`

Для корректной работы этого примера необходимо вручную добавить следующие файлы:

- `examples/locale_switching/assets/fonts/NotoSans-Regular.ttf` — Шрифт Noto Sans (Regular)
- `examples/locale_switching/assets/fonts/NotoSans-Bold.ttf` — Шрифт Noto Sans (Bold)

Эти шрифты необходимы для поддержки кириллицы (ru-RU) и предотвращения проблем с отображением текста при переключении языков.
